How this works

A collector reads each repository's CONTRIBUTING, AI policy, AGENTS.md / CLAUDE.md, pull request templates, workflows and labels (plus the organisation's .github fallback) through the GitHub API, and applies keyword rules. Each verdict keeps the file and line it came from. Where the rules disagree or only partly match, the verdict is Needs review instead of a guess. Verdicts marked reviewed were set by hand after reading the cited text; data/reviews.json records who reviewed each one and when. A review is flagged source changed when the cited file changes.

Not stated means the files we read say nothing we recognise. It does not mean AI contributions are welcome. Policies can also live in places we do not read (wikis, websites, discussions).

Maintainers: if a verdict is wrong or out of date, request a correction.
